# Личный дневник — спецификация продукта

Документ описывает продуктовую идею «Личный дневник» — приложение для ведения записей,
в котором есть три больших модуля: **редактор с шаблонами**, **вишлист** и **картотека людей**.

Спецификация собрана и структурирована на основе исходных идей заказчика. Всё, что было
добавлено сверх исходных формулировок (уточнения, крайние случаи, модель данных, разбиение
на этапы), помечено как проектное решение или как открытый вопрос. Полный перечень того,
во что превратилась каждая исходная фраза, — в [14-traceability.md](14-traceability.md).

## Как читать требования

Требования пронумерованы и сгруппированы по префиксам, чтобы на них можно было ссылаться
в задачах и тестах:

| Префикс | Область |
| --- | --- |
| `ED-*` | Редактор, шаблоны, шрифты и стили |
| `WL-*` | Вишлист |
| `PPL-*` | Картотека людей |
| `MUS-*` | Музыкальный виджет |
| `WID-*` | Движок виджетов |
| `TPL-*` | Каталог шаблонов записей |
| `DS-*` | Дизайн-система |
| `PORT-*` | Экспорт, импорт, резервные копии |
| `NAV-*` | Навигация, экран «Сегодня», корзина |
| `SRCH-*` | Поиск |
| `TAG-*` | Теги |
| `CAL-*` | Календарь |
| `SET-*` | Настройки |
| `ONB-*` | Онбординг и пустые состояния |
| `STAT-*` | Статистика |
| `UI-*` | Правила компоновки форм |
| `NFR-*` | Нефункциональные требования |
| `US-*`, `SC-*`, `AS-*` | Пользовательские истории, сквозные сценарии, антисценарии |
| `AC-*`, `TC-*` | Приёмочные критерии и тест-кейсы |
| `Q1…Q31` | Открытые вопросы |

Приоритеты означают обязательность внутри своей функции, а не попадание в MVP:
**M** (must — без этого функцию нельзя выпускать), **S** (should — следующая волна),
**C** (could — по желанию). Состав MVP задаётся списком функций в
[06-roadmap.md](06-roadmap.md), а не выборкой всех требований с приоритетом M.
