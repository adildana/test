# 10. Сквозные разделы

Функции, не принадлежащие ни одному модулю, но без которых модули не складываются в
приложение: навигация, поиск, теги, календарь, настройки, онбординг, корзина.

---

## 10.1 Навигация и главный экран

| ID | Приор. | Требование |
| --- | --- | --- |
| NAV-01 | M | Основные разделы: **Сегодня**, **Дневник**, **Книги**, **Вишлист**, **Люди**, **Календарь**, **Музыка**, **Настройки** |
| NAV-02 | M | На десктопе — боковое меню, свёртываемое до иконок; на телефоне — нижняя панель из 4 основных разделов и «Ещё» |
| NAV-03 | M | Текущий раздел явно выделен; при возврате в раздел восстанавливается позиция прокрутки и активные фильтры |
| NAV-04 | M | Кнопка быстрого создания (`+`) доступна из любого раздела и предлагает: запись, запись из шаблона, желание, человека |
| NAV-05 | S | Адресация состоянием: у записи, человека, вишлиста и фильтра есть свой URL, работают кнопки «назад/вперёд» браузера |
| NAV-06 | S | Недавно открытое: список последних 10 объектов в быстром доступе |
| NAV-07 | M | Мини-плеер музыкального виджета живёт над навигацией и не прерывается при переходах между разделами; закрывается одним нажатием (MUS-08, MUS-64) |

### Экран «Сегодня»

Первое, что видит пользователь при входе. Собирает данные из всех модулей — именно он
превращает три раздела в одно приложение.

| ID | Приор. | Требование |
| --- | --- | --- |
| NAV-10 | M | Блок «Записать день»: кнопка новой записи; если запись за сегодня уже есть — кнопка «Продолжить запись» |
| NAV-11 | M | Блок «Ближайшие даты»: события на 30 дней вперёд с обратным отсчётом и именами людей |
| NAV-12 | M | Блок «Непрочитанные напоминания»: те, что пришли, но не были открыты |
| NAV-13 | S | Блок «Читаю сейчас»: книги в статусе «Читаю» с датой начала |
| NAV-14 | S | Блок «В этот день год назад»: записи за ту же дату прошлых лет |
| NAV-15 | S | Состав и порядок блоков настраивается, блоки можно скрыть |
| NAV-16 | M | Пустое состояние экрана осмысленно: если данных нет, показываются подсказки, что можно сделать первым (см. 11.3) |

## 10.2 Поиск

| ID | Приор. | Требование |
| --- | --- | --- |
| SRCH-01 | M | Единый поиск по всем модулям, открывается по `Ctrl/Cmd+K` и по иконке |
| SRCH-02 | M | Результаты сгруппированы по типу: записи, книги, люди, желания, шаблоны |
| SRCH-03 | M | Фильтры: тип объекта, период, тег, шаблон, категория людей |
| SRCH-04 | M | Поиск по всем текстовым полям, включая заметки о людях, комментарии и поля шаблонов |
| SRCH-05 | M | В результате показывается фрагмент с подсветкой совпадения; при открытии объекта совпадение подсвечено |
| SRCH-06 | M | Морфология русского языка: «книги» находит «книга», «читал» находит «читать» |
| SRCH-07 | M | Опечатки в именах: «Марья» находит «Мария» (нечёткое совпадение по именам и прозвищам) |
| SRCH-08 | S | Сохранённые поисковые запросы с именем, закрепляемые в меню |
| SRCH-09 | S | Поиск по дате в свободной форме: «март 2024», «прошлое лето» |
| SRCH-10 | M | Скорость: первые результаты не позже 300 мс при 5000 записей |

## 10.3 Теги

| ID | Приор. | Требование |
| --- | --- | --- |
| TAG-01 | M | Теги на записях, желаниях и людях; ввод с автодополнением по существующим |
| TAG-02 | M | Единый справочник тегов: переименование тега меняет его везде, где он использован |
| TAG-03 | M | Слияние тегов (например, «книга» и «книги» в один) с подтверждением |
| TAG-04 | M | Регистр и лишние пробелы нормализуются; `Книги` и `книги` — один тег |
| TAG-05 | S | Цвет тега; фильтр по тегу из любого списка одним нажатием |
| TAG-06 | S | Удаление неиспользуемых тегов одной операцией |

## 10.4 Календарь

| ID | Приор. | Требование |
| --- | --- | --- |
| CAL-01 | M | Календарь на месяц с отметками: дни с записями, важные даты людей |
| CAL-02 | M | Клик по дню открывает записи и события этого дня; клик по пустому дню создаёт запись с этой датой |
| CAL-03 | M | Список важных дат на год вперёд с группировкой по месяцам (PPL-45) |
| CAL-04 | S | Переключение месяц / год; год показывает плотность записей (по принципу «теплокарты») |
| CAL-05 | S | Выгрузка важных дат в `.ics` (PPL-47) |
| CAL-06 | M | Первый день недели — понедельник для русской локали (NFR-61); сегодняшний день выделен |

## 10.5 Настройки

Структура раздела и требования к нему:

| Подраздел | Содержимое |
| --- | --- |
| **Профиль** | Имя, e-mail, аватар, смена пароля, удаление аккаунта (NFR-10) |
| **Внешний вид** | Тема (светлая/тёмная/системная), плотность интерфейса, размер шрифта интерфейса |
| **Шрифты** | Загрузка и управление шрифтами (ED-60…ED-69) |
| **Стили текста** | Наборы стилей и редактор стиля (ED-80…ED-88) |
| **Шаблоны** | Библиотека шаблонов, создание и редактирование (ED-40…ED-47) |
| **Уведомления** | Каналы, время по умолчанию, значения по умолчанию для новых дат (PPL-56), «не беспокоить» (PPL-64), журнал (PPL-65) |
| **Категории людей** | Управление категориями (PPL-03) |
| **Регион** | Язык, часовой пояс, основная валюта, формат даты |
| **Приватность** | Блокировка кодом (NFR-04), разрешение внешних запросов (WL-10, NFR-07), музыкальный виджет и его согласие (MUS-50, MUS-51), управление публичными ссылками (WL-11) |
| **Музыка** | Громкость по умолчанию, автозапуск дисков, пояснение об ограничениях фонового воспроизведения (MUS-10, MUS-61) |
| **Данные** | Экспорт, импорт, резервные копии, использованная квота (Q16), корзина |

| ID | Приор. | Требование |
| --- | --- | --- |
| SET-01 | M | Все настройки применяются немедленно, без кнопки «Сохранить»; результат виден сразу |
| SET-02 | M | У каждой настройки есть пояснение в одну строку — что именно изменится |
| SET-03 | M | Опасные действия (удаление аккаунта, отзыв публичных ссылок, удаление шрифта) требуют подтверждения и объясняют последствия |
| SET-04 | M | Поиск по настройкам |
| SET-05 | M | Раздел «Данные» показывает занятое место с разбивкой: фото, шрифты, вложения |
| SET-06 | S | Сброс настроек внешнего вида к значениям по умолчанию |

## 10.6 Онбординг и пустые состояния

| ID | Приор. | Требование |
| --- | --- | --- |
| ONB-01 | M | Онбординг не длиннее трёх шагов, каждый шаг пропускается |
| ONB-02 | M | При регистрации создаются данные по умолчанию: категории людей, вишлист «Мои желания», набор стилей, системные шаблоны |
| ONB-03 | M | Запрос на разрешение уведомлений выдаётся не при первом входе, а в момент, когда пользователь впервые включает напоминание о дате — тогда причина запроса очевидна |
| ONB-04 | M | Пустое состояние каждого раздела объясняет назначение раздела и содержит кнопку первого действия (см. 11.3) |
| ONB-05 | S | Демонстрационное наполнение по желанию («показать пример») с возможностью удалить одним действием |
| ONB-06 | S | Подсказки по горячим клавишам, появляющиеся однократно и отключаемые |

## 10.7 Корзина и история

| ID | Приор. | Требование |
| --- | --- | --- |
| NAV-40 | M | Корзина: удалённые записи, люди и желания хранятся 30 дней, восстанавливаются одним действием (5.9) |
| NAV-41 | M | Немедленная отмена удаления в течение 10 секунд всплывающим уведомлением (WL-05) |
| NAV-42 | M | Окончательное удаление из корзины — с подтверждением и предупреждением о необратимости |
| NAV-43 | S | История версий записи: снимок сохраняется при каждом существенном изменении, доступен просмотр и восстановление (ED-14) |
| NAV-44 | S | Автоочистка корзины по расписанию с уведомлением за 3 дня до удаления |

## 10.8 Статистика

| ID | Приор. | Требование |
| --- | --- | --- |
| STAT-01 | S | Статистика дневника: количество записей по месяцам, серия дней подряд, самые частые теги |
| STAT-02 | S | Статистика чтения (ED-51): книг за период, средняя оценка, распределение по жанрам |
| STAT-03 | S | Статистика вишлиста: сколько желаний исполнено, средняя цена, распределение по приоритетам |

| STAT-05 | M | Любая статистика считается только по собственным данным пользователя и никуда не отправляется (NFR-07) |
