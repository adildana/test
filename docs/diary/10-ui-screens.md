# 11. Экраны, состояния и тексты интерфейса

Раздел фиксирует компоновку ключевых экранов, поведение в пустых и ошибочных состояниях и
формулировки интерфейсных текстов. Макеты схематичны: они задают состав и приоритет
элементов, а не визуальный стиль.

---

## 11.2 Правила компоновки форм

Единые правила, применимые ко всем анкетам (записи, желания, люди):

| ID | Приор. | Требование |
| --- | --- | --- |
| UI-01 | M | В каждой анкете обязательное поле ровно одно и оно первое; звёздочкой помечается только оно |
| UI-02 | M | Необязательные поля скрыты за блоком «Подробнее» со счётчиком заполненных полей (PPL-12) |
| UI-03 | M | Списочные поля (прозвища, цвета, ссылки, «любит») добавляются кнопкой «+» и по `Enter`; удаляются кнопкой на строке, без диалога подтверждения (действие обратимо через отмену) |
| UI-04 | M | Порядок элементов в списочных полях меняется перетаскиванием, у элемента есть ручка `⇅`; на телефоне — кнопки «вверх/вниз» в меню элемента |
| UI-05 | M | Изменения сохраняются автоматически с индикатором состояния: «сохраняется…», «сохранено», «не сохранено — повторить» |
| UI-06 | M | Ошибки валидации показываются рядом с полем, после ухода из поля, и не блокируют остальную форму |
| UI-07 | M | Мобильная клавиатура соответствует типу поля: числовая для цены, ссылочная для URL, телефонная для номера |
| UI-08 | S | Форма помнит, был ли раскрыт блок «Подробнее», и восстанавливает это состояние (PPL-11, WL-06) |

## 11.3 Пустые состояния

Пустое состояние — не «нет данных», а объяснение и первое действие (ONB-04).

| Экран | Заголовок | Пояснение | Кнопка |
| --- | --- | --- | --- |
| Сегодня (всё пусто) | С чего начнём? | Дневник, желания и важные даты живут здесь | Написать первую запись |
| Дневник | Пока ни одной записи | Запись — это день, мысль или событие. Можно начать с шаблона | Новая запись · Выбрать шаблон |
| Книги | Ни одной книги | Отмечайте прочитанное, ставьте оценки и сохраняйте цитаты | Добавить книгу |
| Вишлист | Список желаний пуст | Достаточно названия — фото, цену и ссылку добавите позже | Добавить желание |
| Люди | Никого не добавлено | Храните дни рождения, привычки и заметки о близких | Добавить человека |
| Календарь | Важных дат нет | Даты появятся здесь, когда вы добавите их людям | Перейти к людям |
| Поиск | Ничего не нашлось по «…» | Попробуйте другое слово или снимите фильтры | Сбросить фильтры |
| Корзина | Корзина пуста | Удалённое хранится 30 дней и может быть восстановлено | — |
| Шрифты | Свои шрифты не загружены | Загрузите файл шрифта, чтобы использовать его в стилях текста | Загрузить шрифт |

## 11.4 Тексты интерфейса

Правила формулировок:

- Обращение на «вы», без восклицательных знаков и заигрывания.
- Сообщение об ошибке говорит, что произошло и что сделать, и никогда не винит пользователя.
- Названия действий — глаголы («Скачать», «Добавить»), а не существительные («Скачивание»).
- Никаких технических терминов в сообщениях пользователю: не «HTTP 413», а «файл слишком большой».

| Ситуация | Текст |
| --- | --- |
| Автосохранение прошло | Сохранено |
| Нет сети при сохранении | Не удалось сохранить — проверьте соединение. Текст сохранён на устройстве. [Повторить] |
| Позиция удалена | Желание удалено. [Отменить] |
| Человек удалён | Карточка перенесена в корзину, там она хранится 30 дней. [Отменить] |
| Удаление категории с людьми | В категории «Коллеги» 12 человек. Куда их перенести? [Выбрать категорию] [Оставить без категории] |
| Удаление используемого шрифта | Шрифт «MyHand» используется в 2 стилях. Чем заменить? [Выбрать шрифт] [Использовать системный] |
| Неверный HEX-цвет | Введите цвет в виде #A1B2C3 |
| Недопустимая ссылка | Такую ссылку открыть нельзя. Допустимы адреса, начинающиеся с http:// или https:// |
| Файл слишком большой | Файл больше 15 МБ. Уменьшите изображение и попробуйте снова |
| Квота хранилища исчерпана | Место закончилось: занято 50 МБ из 50 МБ. Удалите ненужные файлы или обратитесь к настройкам данных |
| Шрифт без кириллицы | В шрифте нет русских букв — они будут показаны другим шрифтом |
| Экспорт PDF готовится | Готовим PDF: 24 из 100 позиций |
| Уведомление о ДР (в день) | Сегодня день рождения у Марии — 34 года |
| Уведомление о ДР (заранее) | Через 7 дней день рождения у Марии. Любит пионы и чёрный шоколад |
| Публичная ссылка включена | Ссылка создана. Её увидит любой, кому вы её отправите. [Скопировать] [Отозвать] |
| Подтверждение прав на шрифт | Подтверждаю, что имею право использовать этот шрифт |
| Удаление аккаунта | Будут удалены все записи, желания, люди и файлы. Это необратимо. Введите «удалить», чтобы подтвердить |

## 11.5 Горячие клавиши

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Поиск по всему | `Ctrl+K` | `Cmd+K` |
| Новая запись | `Ctrl+Alt+N` | `Cmd+Opt+N` |
| Сохранить сейчас | `Ctrl+S` | `Cmd+S` |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Shift+Z` | `Cmd+Z` / `Cmd+Shift+Z` |
| Полужирный / курсив / подчёркнутый | `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | `Cmd+B` / `Cmd+I` / `Cmd+U` |
| Зачёркнутый | `Ctrl+Shift+X` | `Cmd+Shift+X` |
| Заголовок 1–3 | `Ctrl+Alt+1…3` | `Cmd+Opt+1…3` |
| Обычный текст | `Ctrl+Alt+0` | `Cmd+Opt+0` |
| Список / нумерованный / чек-лист | `Ctrl+Shift+8` / `9` / `7` | `Cmd+Shift+8` / `9` / `7` |
| Вставить ссылку | `Ctrl+Shift+U` | `Cmd+Shift+U` |
| Очистить форматирование | `Ctrl+\` | `Cmd+\` |
| Вставить без форматирования | `Ctrl+Shift+V` | `Cmd+Shift+V` |
| Свернуть/развернуть панель форматирования | `Ctrl+Shift+F` | `Cmd+Shift+F` |
| Режим фокуса | `Ctrl+Shift+D` | `Cmd+Shift+D` |
| Перейти в панель форматирования (доступность) | `F10` | `F10` |
| Музыка: пауза / продолжить | `Ctrl+Alt+Space` | `Cmd+Opt+Space` |
| Музыка: следующий / предыдущий трек | `Ctrl+Alt+→` / `←` | `Cmd+Opt+→` / `←` |
| Список горячих клавиш | `?` | `?` |

Требование: экран `?` со списком горячих клавиш обязателен, а сами клавиши не должны
перекрывать системные и браузерные сочетания (проверяется на всех поддерживаемых браузерах).
Отдельное требование к музыкальному виджету: одиночный пробел, стрелки и `Enter` всегда
остаются вводом текста, поэтому управление плеером живёт только на сочетаниях с модификаторами
(MUS-15).
