# 3. Вишлист

Исходные формулировки заказчика:

> Вишлист: где можно заполнить анкету подарка, которого хочешь, и через плюс продолжить
> список — шаблончик. Название подарка. Фото подарка прикрепить можно. Цена, если есть.
> Ссылка, где взять, если есть. Комментарий. Весь этот вишлист можно скачать как PDF или
> перед скачиванием выбрать.

---

## 3.1 Структура

Вводится два уровня, чтобы «плюс» из требования работал предсказуемо:

- **Вишлист** — именованный список (например, «На день рождения», «Хочу когда-нибудь»,
  «Идеи подарков для мамы»). У пользователя может быть несколько вишлистов.
- **Позиция** — одна анкета подарка внутри вишлиста.

Если пользователю не нужны несколько списков, он работает с одним, созданным по умолчанию,
и второго уровня попросту не замечает.

## 3.2 Анкета подарка

| Поле | Тип | Обяз. | Поведение |
| --- | --- | --- | --- |
| Название подарка | текст | **да** | Единственное обязательное поле. До 200 символов |
| Фото | изображения | нет | Несколько файлов; первое — обложка позиции. Загрузка файлом, перетаскиванием, вставкой из буфера, с камеры на мобильном |
| Цена | деньги | нет | Число + валюта. Валюта по умолчанию берётся из настроек пользователя. Допускается диапазон («от 3000 до 5000») и текстовое значение («не знаю») |
| Ссылка, где взять | URL | нет | Несколько ссылок. Показывается доменом («ozon.ru»), а не полным адресом |
| Комментарий | длинный текст | нет | Свободный текст: размер, цвет, модель, пожелания |

Дополнительные поля (проектное предложение — всё опционально и скрыто до раскрытия блока
«Подробнее», чтобы не удлинять форму):

| Поле | Тип | Зачем |
| --- | --- | --- |
| Приоритет | выбор: очень хочу / хочу / было бы неплохо | Помогает дарящему выбрать |
| Статус | выбор: актуально / подарено / куплено сам / больше не актуально | Позиция не удаляется, а закрывается — история сохраняется |
| Для кого | ссылка на человека | Превращает вишлист в список идей подарков другим (связь с модулем «Люди») |
| Теги | теги | Группировка: «книги», «дом», «спорт» |
| Размер / характеристики | текст | Частый случай для одежды и обуви |
| Дата добавления | дата | Заполняется автоматически |

## 3.3 Требования к работе со списком

| ID | Приор. | Требование |
| --- | --- | --- |
| WL-01 | M | Кнопка «+» добавляет новую пустую анкету в конец списка и сразу ставит курсор в поле «Название» |
| WL-02 | M | Заполненная анкета сохраняется автоматически; черновик с пустым названием не сохраняется и при уходе со страницы отбрасывается без диалога |
| WL-03 | M | Позиции отображаются карточками (фото + название + цена + приоритет) с переключением на компактный список |
| WL-04 | M | Изменение порядка позиций перетаскиванием; порядок сохраняется |
| WL-05 | M | Удаление позиции с возможностью отмены в течение 10 секунд («Позиция удалена — Отменить») |
| WL-06 | M | Раскрывающийся блок «Подробнее» для необязательных полей; состояние раскрытия запоминается для всей формы, а не для отдельной позиции |
| WL-07 | S | Несколько вишлистов: создание, переименование, удаление, перенос и копирование позиции между списками |
| WL-08 | S | Фильтры и сортировка: по приоритету, цене, дате добавления, статусу, тегу |
| WL-09 | S | Итоговая сумма выбранных позиций (с пересчётом в основную валюту по сохранённому курсу) |
| WL-10 | S | Добавление позиции по ссылке: пользователь вставляет URL, приложение подставляет название, фото и цену из Open Graph-разметки страницы. Только по явному действию, с возможностью отредактировать результат (см. Q6 о приватности) |
| WL-11 | C | Публичная ссылка на вишлист: доступ по секретному адресу, только чтение, без индексации поисковиками, с возможностью отозвать ссылку |
| WL-12 | C | Скрытая бронь: гость по публичной ссылке помечает позицию как «я это дарю», владелец брони не видит (чтобы не портить сюрприз) |

## 3.4 Экспорт в PDF

Требование заказчика: «весь этот вишлист можно скачать как PDF или перед скачиванием выбрать».
Трактуется как два режима: быстрый экспорт всего списка и экспорт с предварительным выбором.

| ID | Приор. | Требование |
| --- | --- | --- |
| WL-20 | M | Кнопка «Скачать PDF» экспортирует весь текущий вишлист в порядке, заданном пользователем |
| WL-21 | M | Режим выбора: у каждой позиции появляется флажок, есть «Выбрать все» / «Снять все», счётчик выбранных, кнопка «Скачать выбранное (N)» |
| WL-22 | M | Диалог настроек экспорта перед скачиванием: что включать (фото, цены, ссылки, комментарии, приоритет, теги), формат страницы (A4 / Letter), ориентация, макет |
| WL-23 | M | Три макета: **список** (компактно, по строке на позицию), **карточки** (2–3 на страницу с крупными фото), **сетка** (галерея фото с подписями) |
| WL-24 | M | Настройки экспорта запоминаются и подставляются в следующий раз |
| WL-25 | M | Оформление PDF использует текстовые стили и загруженные пользователем шрифты (см. ED-60…ED-88); при недоступности шрифта используется системный, пользователь получает предупреждение |
| WL-26 | M | Титульная страница: название вишлиста, имя владельца (если указано), дата формирования; отключается в настройках |
| WL-27 | S | Ссылки в PDF кликабельны; опционально рядом печатается QR-код — чтобы ссылка работала и на бумажной копии |
| WL-28 | S | Предпросмотр перед скачиванием с постраничной навигацией |
| WL-29 | S | Имя файла по шаблону: `Вишлист — <название> — <ГГГГ-ММ-ДД>.pdf`; корректная обработка символов, недопустимых в именах файлов |
| WL-30 | C | Экспорт в другие форматы: изображение (PNG одной картинкой), CSV, печать напрямую из браузера с корректными разрывами страниц |

### Технические замечания к PDF

- Экспорт должен корректно работать при 100+ позициях с фотографиями: изображения
  масштабируются под макет до вставки в документ, а не вставляются в исходном разрешении.
- Кириллица требует шрифта с соответствующим покрытием — базовые шрифты PDF его не имеют,
  поэтому шрифт обязательно встраивается в документ.
- Позиции не должны разрываться между страницами (карточка целиком переносится на
  следующую страницу).
- Скрытые статусы («подарено», «не актуально») по умолчанию в экспорт не попадают;
  включаются флажком в настройках.
