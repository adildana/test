# 18. Дизайн-система

Раздел фиксирует решения об оформлении интерфейса. Это не «как сделать красиво», а набор
ограничений, без которых интерфейс неизбежно разъедется: в продукте, где пользователь
загружает свои шрифты, задаёт свои цвета и вставляет чужой контент, нужна чёткая граница
между **оформлением интерфейса** и **оформлением содержимого**.

Значения токенов ниже — рабочее предложение, а не догма: их можно менять, важно, чтобы они
задавались в одном месте и использовались только через имена.

---

## 18.1 Принципы

1. **Главный элемент — текст пользователя.** Интерфейс отступает: спокойные нейтральные
   цвета, минимум рамок, акцент только там, где нужно действие.
2. **Интерфейс не спорит с содержимым.** Пользовательские шрифты, цвета и стили действуют
   внутри записи, но не в меню, кнопках и диалогах (DS-01).
3. **Один источник значений.** Ни один цвет, отступ или радиус не задаётся числом в компоненте —
   только токеном.
4. **Читаемость выше выразительности.** Любое оформление, которое проваливает проверку
   контраста, считается дефектом, а не стилем (NFR-51).

## 18.2 Граница между интерфейсом и содержимым

Самое важное решение раздела. Пользователь может загрузить рукописный шрифт без кириллицы и
выбрать светло-жёлтый текст — и это его право внутри записи. Но если то же самое применится к
интерфейсу, приложение станет неработоспособным.

| ID | Приор. | Требование |
| --- | --- | --- |
| DS-01 | M | Пользовательские шрифты и текстовые стили (ED-60…ED-88) применяются только к содержимому: тело записи, заголовок записи, поля шаблонов, комментарии, экспорт. Интерфейс всегда использует системные токены |
| DS-02 | M | Размер интерфейсного шрифта настраивается отдельно от контентного (10.5, «Внешний вид») |
| DS-03 | M | Пользовательские цвета (текста, фона, тегов, категорий, любимых цветов человека) отображаются только как содержимое или как метка; они не задают цвет кнопок, ссылок и служебных элементов |
| DS-04 | M | При выборе пользователем цвета проверяется контраст с фоном; при недостаточном показывается предупреждение и предлагается ближайший подходящий оттенок (NFR-51) |
| DS-05 | M | Пользовательский цвет, используемый как метка (тег, категория, любимый цвет), всегда сопровождается подписью или иконкой (NFR-52) |
| DS-06 | M | Область содержимого визуально отделена от интерфейса: у неё своя ширина строки, свои отступы и своя типографика |

## 18.3 Цвет

Нейтральная шкала — основа: интерфейс почти целиком строится на ней. Акцент один, потому что
два акцента всегда начинают конкурировать.

| Токен | Светлая тема | Тёмная тема | Где |
| --- | --- | --- | --- |
| `bg-canvas` | `#fbfaf8` | `#14151a` | Фон приложения |
| `bg-surface` | `#ffffff` | `#1c1e25` | Карточки, панели, диалоги |
| `bg-surface-raised` | `#ffffff` | `#232631` | Всплывающие панели, меню |
| `bg-content` | `#ffffff` | `#191b21` | Область текста записи |
| `bg-subtle` | `#f2f0ec` | `#22242c` | Наведение, чередование строк |
| `border-default` | `#e4e1db` | `#2e313b` | Границы, разделители |
| `border-strong` | `#c9c5bd` | `#3d414e` | Поля ввода, активные границы |
| `text-primary` | `#1d1c1a` | `#eceef2` | Основной текст интерфейса |
| `text-secondary` | `#5c5a55` | `#a5a9b4` | Подписи, вспомогательное |
| `text-tertiary` | `#8b8880` | `#767b88` | Подсказки, счётчики |
| `accent` | `#4a6cf0` | `#7b93ff` | Кнопки, ссылки, фокус |
| `accent-subtle` | `#eef1fe` | `#232a44` | Фон активного состояния |
| `success` | `#2f7a4d` | `#5fbe86` | «Любит», сохранено, серии |
| `warning` | `#9a6212` | `#e0a44a` | Квоты, предупреждения о шрифтах |
| `danger` | `#a33232` | `#f08a8a` | «Не любит», удаление, ошибки |
| `focus-ring` | `#4a6cf0` | `#7b93ff` | Обводка фокуса, 2 px, смещение 2 px |

| ID | Приор. | Требование |
| --- | --- | --- |
| DS-10 | M | Тёмная тема — не инверсия, а отдельный набор значений тех же токенов; проверяется на контраст независимо |
| DS-11 | M | Семантические цвета (`success`, `warning`, `danger`) никогда не используются декоративно, только по смыслу |
| DS-12 | M | Контраст основного текста к фону — не ниже 4.5:1, крупного и иконок — не ниже 3:1 (NFR-51) |
| DS-13 | S | Пользователь может выбрать другой акцентный цвет из ограниченного набора проверенных на контраст вариантов |

## 18.4 Типографика

Два независимых набора: интерфейсный и контентный.

| Роль | Шрифт | Кегль / интерлиньяж | Где |
| --- | --- | --- | --- |
| `ui-title` | интерфейсный | 20 / 1.3 | Заголовки экранов |
| `ui-body` | интерфейсный | 15 / 1.45 | Основной интерфейс |
| `ui-small` | интерфейсный | 13 / 1.4 | Подписи, метаданные |
| `ui-mono` | моноширинный | 13 / 1.5 | HEX-коды, идентификаторы |
| `content-h1` | контентный (стиль пользователя) | 28 / 1.25 | Заголовок 1 в записи |
| `content-h2` | контентный | 22 / 1.3 | Заголовок 2 |
| `content-h3` | контентный | 18 / 1.35 | Заголовок 3 |
| `content-body` | контентный | 17 / 1.6 | Тело записи |
| `content-quote` | контентный | 17 / 1.6, курсив | Цитата |
| `content-caption` | контентный | 14 / 1.4 | Подписи к фото |

| ID | Приор. | Требование |
| --- | --- | --- |
| DS-20 | M | Ширина строки содержимого ограничена 66–72 знаками; в режиме фокуса (ED-10) — тем же значением |
| DS-21 | M | Кегль контентного текста по умолчанию не меньше 16 px: дневник читают долго |
| DS-22 | M | Интерфейсный шрифт — системный (`system-ui`), чтобы приложение выглядело родным на каждой платформе и не грузило лишние файлы |
| DS-23 | M | Значения `content-*` — это значения по умолчанию для набора стилей; пользователь их переопределяет (ED-81), интерфейсные — нет |

| --- | --- | --- |
| Шкала отступов | 2, 4, 8, 12, 16, 24, 32, 48, 64 | Только эти значения; промежуточных нет |
| `radius-sm` | 6 px | Поля ввода, теги, чипы |
| `radius-md` | 10 px | Кнопки, карточки |

| ID | Приор. | Требование |
| --- | --- | --- |
| DS-30 | M | Тени используются только для отделения слоёв, а не для украшения; в тёмной теме заменяются границами, потому что тень на тёмном фоне не читается |
| DS-31 | M | Плотность интерфейса переключается («обычная» / «компактная») изменением одной ступени шкалы отступов, а не правкой компонентов |

## 18.6 Движение

| Токен | Значение | Применение |
| --- | --- | --- |
| `motion-fast` | 120 мс | Наведение, нажатие, появление подсказки |
| `motion-base` | 200 мс | Выдвижение панели форматирования, раскрытие «Подробнее» |
| `motion-slow` | 320 мс | Диалоги, переходы между экранами |
| Кривая | `cubic-bezier(0.2, 0, 0, 1)` | Всё, кроме вращения диска |
| Вращение диска | линейная, 8 с на оборот | Музыкальный виджет (MUS-06) |

| ID | Приор. | Требование |
| --- | --- | --- |
| DS-40 | M | При системной настройке «уменьшить движение» все переходы сокращаются до мгновенных, вращение и параллакс отключаются (NFR-56, MUS-14) |
| DS-41 | M | Анимация никогда не задерживает ввод: панель форматирования и поля реагируют мгновенно, анимируется только их визуальное появление |

## 18.7 Компоненты и состояния

Каждый компонент обязан иметь все перечисленные состояния. Отсутствие состояния — дефект,
а не «не предусмотрено».

| Компонент | Состояния |
| --- | --- |
| Кнопка (основная, обычная, тихая, опасная) | обычное, наведение, нажатие, фокус, отключена, загрузка |
| Поле ввода | пустое с подсказкой, заполненное, фокус, ошибка, отключено, только чтение |
| Флажок, переключатель, радио | вкл, выкл, промежуточное, фокус, отключено |
| Выпадающий список | закрыт, открыт, поиск внутри, пусто, много значений |
| Карточка (желание, человек, книга, диск) | обычная, наведение, выбрана, перетаскивается, недоступна |
| Списочная строка | обычная, наведение, выбрана, перетаскивается, удалена (с отменой) |
| Диалог | обычный, опасное действие, загрузка, ошибка |
| Всплывающее уведомление | информация, успех, ошибка, с действием «Отменить» |
| Подсказка | по наведению, по фокусу с клавиатуры |
| Панель форматирования | свёрнута, развёрнута, плавающая у выделения, узкий экран |
| Рамка виджета | обычная, свёрнута, ошибка данных, неизвестный тип, требуется согласие |
| Пустое состояние | заголовок, пояснение, действие (11.3) |
| Индикатор сохранения | сохраняется, сохранено, не сохранено с повтором |

| ID | Приор. | Требование |
| --- | --- | --- |
| DS-50 | M | Все интерактивные элементы имеют видимый фокус токеном `focus-ring`; фокус не убирается ни ради красоты, ни «потому что мышью не видно» |
| DS-51 | M | Минимальная область нажатия — 44×44 px на сенсорных экранах, включая кнопки в списочных строках и на диске |
| DS-52 | M | Загрузка показывается на месте будущего содержимого (скелет), а не крутящимся индикатором поверх экрана |
| DS-53 | M | Опасные действия используют роль `danger` и требуют подтверждения с описанием последствий (SET-03) |
| DS-54 | M | Компонент не изобретается заново: если нужного нет в наборе, он добавляется в набор, а не делается локально в одном экране |

## 18.8 Иконки

| ID | Приор. | Требование |
| --- | --- | --- |
| DS-60 | M | Единый набор линейных иконок, толщина линии 1.5 px, размеры 16 / 20 / 24 px |
| DS-61 | M | Иконка без подписи допускается только для общеизвестных действий и обязательно имеет текстовое название для экранных читалок (NFR-53) |

## 18.9 Адаптивность

| Точка перелома | Ширина | Что меняется |
| --- | --- | --- |
| Телефон | < 600 px | Нижняя навигация, панель форматирования — прокручиваемая лента, диалоги на весь экран |
| Планшет | 600–1024 px | Боковое меню иконками, двухколоночные списки |
| Десктоп | > 1024 px | Полное боковое меню, содержимое по центру с ограничением ширины (DS-20) |
| Широкий | > 1440 px | Дополнительная колонка (например, лента комментариев рядом с анкетой человека, Q15) |

| ID | Приор. | Требование |
| --- | --- | --- |
| DS-70 | M | Все основные сценарии выполнимы одной рукой на телефоне: главные действия в нижней половине экрана |
| DS-71 | M | Интерфейс не ломается при системном увеличении шрифта до 200% (NFR-57) |
| DS-72 | M | Мини-плеер, панель форматирования и клавиатура не перекрывают друг друга (MUS-64) |

## 18.10 Чек-лист приёмки оформления

Проверяется для каждого нового экрана и компонента:

1. Все цвета, отступы и радиусы — через токены, ни одного значения «на глаз».
2. Есть светлая и тёмная темы, обе проверены на контраст.
3. Все состояния из 18.7 присутствуют, включая пустое и ошибочное.
4. Виден фокус, работает клавиатура, у иконок есть названия.
5. Пользовательские шрифты и цвета не протекли в интерфейс (DS-01, DS-03).
6. Проверено на телефоне, при увеличенном системном шрифте и с «уменьшить движение».
7. Тексты — из файлов переводов, множественные числа корректны (NFR-60, NFR-62).
