# 16. Музыкальный виджет-диск

Исходная формулировка заказчика:

> Ещё я хочу, чтобы можно было включать музыкальный виджет диска — работает музыка по
> ссылкам YouTube.

Трактовка: в записи (и не только) можно включить виджет в виде **вращающегося диска
(винила)**, который проигрывает музыку по ссылкам с YouTube. Диск — не просто плеер, а
элемент оформления дневника: запись получает «саундтрек», у человека появляется «его
музыка».

Модуль сознательно описан отдельно, потому что он единственный в продукте зависит от
внешнего сервиса — и это влечёт правовые, технические и приватностные ограничения,
разобранные в 16.6–16.8. Их нужно прочитать до начала реализации.

---

## 16.1 Где появляется диск

| Место | Что это значит | Требования |
| --- | --- | --- |
| **Запись дневника** | Саундтрек дня: что слушал, пока писал | MUS-20 |
| **Карточка человека** | «Его музыка»: любимые песни, подсказка к подарку | MUS-21, PPL-59 |
| **Запись о книге** | Что звучало во время чтения | MUS-22 |
| **Раздел «Музыка»** | Собственная коллекция дисков, не привязанных ни к чему | MUS-23 |
| **Поле шаблона** | Тип поля «музыка» — диск как часть любого своего шаблона | MUS-24, ED-42 |
| **Мини-плеер** | Воспроизведение продолжается при переходах между разделами | MUS-08, NAV-07 |

Виджет всегда необязателен: запись без диска ничем не отличается от обычной, а выключенный
виджет не занимает места на экране (MUS-01).

## 16.2 Как выглядит и ведёт себя диск

Диск в состоянии покоя (плеер ещё не загружен — см. MUS-40):

```
┌──────────────── Саундтрек записи ──────────────┐
│            ╭───────────────╮                   │
│         ╭──╯  ╭─────────╮  ╰──╮                │
│        │     │ обложка   │     │   ← этикетка = │
│        │     │  трека    │     │     превью     │
│         ╰──╮  ╰─────────╯  ╭──╯                │
│            ╰───────────────╯                   │
│                                                │
│   Ludovico Einaudi — Nuvole Bianche            │
│   ▶  1 / 5 треков · 6:03 · youtube.com          │
│   [ ▶ Играть ]  [ + Добавить ]  [ ⋯ ]          │
└────────────────────────────────────────────────┘
```

Диск во время воспроизведения (плеер загружен и виден, вращается только внешнее кольцо —
16.6, вариант A):

```
┌──────────────── Саундтрек записи ──────────────┐
│         ╭─── вращается ───╮                    │
│        │   ┌───────────┐   │                   │
│        │   │  плеер    │   │  ← официальный    │
│        │   │  YouTube  │   │    плеер, видимый │
│        │   └───────────┘   │                   │
│         ╰─────────────────╯                    │
│   Ludovico Einaudi — Nuvole Bianche            │
│   ├────────●──────────────────┤  2:41 / 6:03   │
│   ⏮  ⏸  ⏭   🔊 ──●──   ⟳ один  ⤨ вперемешку   │
│   Треки  ⇅                                     │
│   1. Nuvole Bianche                     ▶  ⋯   │
│   2. Experience                             ⋯   │
│   3. Una Mattina                     ⚠ недоступно │
└────────────────────────────────────────────────┘
```

Мини-плеер (виден в любом разделе, пока играет музыка):

```
┌──────────────────────────────────────────────────────────┐
│ ◉ Nuvole Bianche · Ludovico Einaudi   ⏮ ⏸ ⏭   2:41  ✕   │
└──────────────────────────────────────────────────────────┘
```

## 16.3 Требования: виджет и воспроизведение

| ID | Приор. | Требование |
| --- | --- | --- |
| MUS-01 | M | Виджет включается и выключается в записи одним действием; выключенный виджет не занимает места и не влияет на экспорт |
| MUS-02 | M | Добавление трека вставкой ссылки YouTube; допустимые формы — см. 16.5 |
| MUS-03 | M | Название, исполнитель и обложка подтягиваются по ссылке автоматически; пользователь может исправить их вручную (MUS-35) |
| MUS-04 | M | Диск — это плейлист: несколько треков, добавление через «+», порядок перетаскиванием, удаление трека |
| MUS-05 | M | Управление: воспроизведение/пауза, следующий/предыдущий, позиция, громкость, повтор одного и всех, воспроизведение вперемешку |
| MUS-06 | M | Обложка текущего трека показывается этикеткой диска; во время воспроизведения диск вращается, на паузе вращение останавливается |
| MUS-07 | M | Перемотка: круговым движением по диску **и** обычной полосой — полоса обязательна для точности и доступности |
| MUS-08 | M | Мини-плеер: при переходе между разделами и записями воспроизведение не прерывается (NAV-07) |
| MUS-09 | M | Одновременно играет только один диск; запуск другого останавливает предыдущий |
| MUS-10 | S | Автозапуск при открытии записи — настройка, по умолчанию выключена; на мобильных платформах игнорируется (MUS-60) |
| MUS-11 | S | Позиция воспроизведения запоминается по треку: возврат к записи продолжает с того же места |
| MUS-12 | S | Фрагмент трека: таймкод начала и конца, чтобы диск играл именно нужную часть песни |
| MUS-13 | C | Цвет диска и подложки берётся из обложки трека, а в карточке человека — из его любимого цвета (PPL-70) |
| MUS-14 | M | При системной настройке «уменьшить движение» вращение отключается, воспроизведение работает (NFR-56) |
| MUS-15 | M | Горячие клавиши плеера не конфликтуют с редактором: пробел всегда остаётся пробелом в тексте, управление музыкой — на отдельных сочетаниях (11.5) |
| MUS-16 | M | Виджет полностью управляется с клавиатуры и озвучивается экранным диктором: у кнопок есть названия, у диска — роль слайдера с текущим значением времени (NFR-50, NFR-53) |

## 16.5 Ссылки: разбор и метаданные

Поддерживаемые формы ссылок (MUS-02):

| Форма | Пример | Что берём |
| --- | --- | --- |
| Обычная | `https://www.youtube.com/watch?v=ID` | `video_id` |
| Короткая | `https://youtu.be/ID` | `video_id` |
| С таймкодом | `…watch?v=ID&t=95s` | `video_id`, начало 1:35 (MUS-12) |
| Shorts | `https://www.youtube.com/shorts/ID` | `video_id` |
| Встраиваемая | `https://www.youtube.com/embed/ID` | `video_id` |
| Плейлист | `…playlist?list=PL…` | список треков целиком (MUS-31 про недоступные) |
| Видео в плейлисте | `…watch?v=ID&list=PL…` | по умолчанию один трек; предложение «добавить весь плейлист» |
| Музыкальный поддомен | `https://music.youtube.com/watch?v=ID` | `video_id` |

| ID | Приор. | Требование |
| --- | --- | --- |
| MUS-30 | M | Разбор ссылки выполняется на сервере, чтобы клиент, экспорт и мини-плеер работали с одним и тем же результатом (по аналогии с PPL-25) |
| MUS-31 | M | Понятные состояния недоступности: видео удалено, закрыто автором, недоступно в стране, запрещено к встраиванию, с возрастным ограничением. Для каждого — свой текст (16.9) |
| MUS-32 | M | Доступность проверяется в момент добавления, а не в момент воспроизведения: пользователь узнаёт о проблеме сразу |
| MUS-33 | S | Периодическая проверка треков в фоне; недоступные помечаются в списке, но не удаляются |
| MUS-34 | M | Исходная ссылка сохраняется всегда: даже когда воспроизведение внутри приложения невозможно, ссылку можно открыть в YouTube |
| MUS-35 | S | Ручной ввод названия и исполнителя, если метаданные не получены |
| MUS-36 | M | Некорректная ссылка (не YouTube, недопустимая схема) отклоняется с понятным сообщением; правила проверки — в 5.9 |

Метаданные получаются публичным oEmbed-запросом (`https://www.youtube.com/oembed?url=…`),
не требующим ключа API: этого достаточно для названия и обложки. Data API v3 нужен только
для длительности и разбора плейлистов — решение о ключе выносится в Q20.

## 16.6 Ограничения платформы: как показывать диск

Это главный риск модуля. Правила YouTube для встраивания требуют использовать
**официальный плеер**, не скрывать и не перекрывать его, не отделять аудио от видео и не
блокировать рекламу. Красивый «чистый винил», за которым не видно видео, в эти правила
не вписывается.

Формулировки правил меняются, и их точную редакцию нужно сверить перед реализацией
(вопрос Q18). Ниже — варианты дизайна с оценкой риска:

| Вариант | Как выглядит | Риск |
| --- | --- | --- |
| **A. Диск-рамка** | Официальный плеер видим в центре, вращается только декоративное кольцо вокруг него | Низкий — **рекомендуется** |
| **B. Диск до старта, плеер после** | До нажатия — статичная обложка-винил; после нажатия центр диска «раскрывается» в видимый плеер | Низкий, хорошо сочетается с A |
| C. Диск поверх плеера | Видео перекрыто или обрезано маской, слышно только звук | Высокий: перекрытие плеера — прямое нарушение |
| D. Свой аудиопоток | Извлечение звуковой дорожки из YouTube | Недопустимо: нарушение правил и, вероятно, авторских прав |

**Рекомендация:** сочетание A и B. До нажатия пользователь видит красивый диск (это ещё и
требование приватности MUS-40 — плеер до этого момента вообще не загружается), после
нажатия центр становится настоящим плеером, а «винильность» обеспечивают вращающееся
кольцо, тень и подпись.

| ID | Приор. | Требование |
| --- | --- | --- |
| MUS-40 | M | До явного нажатия «Играть» плеер не загружается: показывается статичная обложка. Это одновременно приватность (16.7) и скорость загрузки записи (NFR-40) |
| MUS-41 | M | Используется только официальный встраиваемый плеер; звук отдельно от видео не извлекается, реклама не блокируется, плеер не перекрывается элементами оформления |
| MUS-42 | M | Размер и видимость плеера соответствуют актуальным правилам встраивания; конкретные значения фиксируются в коде одной константой, чтобы их можно было изменить при смене правил |
| MUS-43 | M | Никакого скачивания, кеширования или локального хранения аудио и видео |
| MUS-44 | S | Архитектура источников расширяемая: добавление другого сервиса (в том числе загрузки своих аудиофайлов) не должно требовать переписывания виджета (Q19) |

## 16.7 Приватность

Модуль конфликтует с принципом «приложение не отправляет данные третьим сторонам»
(NFR-07): встроенный плеер — это обращение к Google с IP-адресом пользователя. Конфликт
решается явным согласием, а не молчаливым исключением из правила.

| ID | Приор. | Требование |
| --- | --- | --- |
| MUS-50 | M | Музыкальный виджет выключен до первого явного согласия пользователя; согласие запрашивается в момент первой попытки включить музыку, с объяснением, что воспроизведение выполняет плеер YouTube и сервис увидит обращение (NFR-12) |
| MUS-51 | M | Согласие отзывается в настройках приватности; после отзыва диски сохраняются как списки ссылок, но плеер не загружается |
| MUS-52 | M | Плеер загружается с домена без отслеживающих cookie (`youtube-nocookie.com`) |
| MUS-53 | M | Обложки треков кешируются на своей стороне, чтобы открытие записи не приводило к запросу к внешнему домену до нажатия «Играть» |
| MUS-54 | M | В экспорт данных попадают ссылки, названия и порядок треков (NFR-20); аудио не экспортируется, потому что не хранится |
| MUS-55 | M | Названия прослушанного не отправляются никуда за пределы приложения и не участвуют в метриках (NFR-73) |

## 16.8 Мобильные платформы и офлайн

| ID | Приор. | Требование |
| --- | --- | --- |
| MUS-60 | M | На мобильных браузерах воспроизведение стартует только после жеста пользователя; настройка автозапуска (MUS-10) там не применяется, и интерфейс это объясняет, а не молчит |
| MUS-61 | M | Продолжение воспроизведения при свёрнутом браузере или заблокированном экране платформой не гарантируется. Интерфейс не обещает фоновое воспроизведение; в настройках есть честное пояснение (Q21) |
| MUS-62 | M | Без сети виджет показывает «музыка недоступна без интернета», при этом сама запись открывается и редактируется (NFR-30) |
| MUS-63 | S | При обрыве сети во время воспроизведения виджет показывает состояние и предлагает повтор, не ломая запись |
| MUS-64 | M | Мини-плеер на телефоне не перекрывает панель форматирования и нижнюю навигацию, сворачивается в узкую полосу (NAV-02) |

## 16.9 Ошибочные состояния и тексты

| Ситуация | Текст |
| --- | --- |
| Первое включение музыки | Музыку проигрывает плеер YouTube — сервис увидит обращение с вашего устройства. Включить музыкальный виджет? [Включить] [Не сейчас] |
| Ссылка не с YouTube | Пока поддерживаются только ссылки с YouTube |
| Ссылка неразборчива | Не удалось распознать ссылку. Скопируйте адрес видео целиком |
| Видео удалено или закрыто | Видео больше недоступно. Ссылка сохранена — можно заменить трек |
| Запрещено встраивание | Автор запретил воспроизведение вне YouTube. [Открыть в YouTube] |
| Недоступно в стране | Видео недоступно в вашей стране |
| Возрастное ограничение | Видео с возрастным ограничением нельзя проиграть здесь. [Открыть в YouTube] |
| Нет сети | Музыка недоступна без интернета |
| Автозапуск на телефоне | Телефон не разрешает включать музыку без вашего нажатия — нажмите «Играть» |
| Плейлист частично недоступен | Добавлено 12 треков, 3 недоступны — они помечены в списке |
| Согласие отозвано | Музыкальный виджет отключён в настройках приватности. [Включить снова] |
