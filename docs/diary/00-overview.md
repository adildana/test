# 1. Общий обзор

## 1.1 Цель продукта

Единое личное пространство, где пользователь ведёт дневник и хранит рядом с записями всё,
что связано с его жизнью и окружением: прочитанные книги, желаемые подарки, информацию о
близких людях и важные даты.

Ключевая идея, отличающая продукт от обычного заметочника: **записи создаются не с пустого
листа, а из шаблонов**, и при этом текст можно оформлять так же свободно, как в Google Docs
или Microsoft Word — вплоть до собственных шрифтов и собственных текстовых стилей.

## 1.2 Целевой пользователь

Частное лицо, которое ведёт дневник для себя. Из этого следуют три важных вывода,
влияющих на все решения ниже:

1. Данные — личные и чувствительные. Приватность важнее социальных функций
   (см. [05-nonfunctional.md](05-nonfunctional.md)).
2. Пользователь один, объёмы небольшие (сотни-тысячи записей), но требования к удобству
   ввода высокие: если заполнять анкету дольше минуты, ей не будут пользоваться.
3. Совместная работа над записями не нужна. Единственный сценарий «наружу» — поделиться
   вишлистом или выгрузить его в PDF.

## 1.3 Модули

```
Личный дневник
├── Записи и редактор
│   ├── выдвижная панель форматирования
│   ├── шаблоны записей (в т.ч. «Оценка прочитанных книг»)
│   └── свои шрифты + свои текстовые стили
├── Вишлист
│   ├── анкеты подарков (название, фото, цена, ссылка, комментарий)
│   └── экспорт в PDF с выбором позиций
├── Люди
│   ├── категории (семья, друзья, коллеги, …)
│   ├── анкета человека (ФИО, прозвища, соцсети, цвета, любимое/нелюбимое, заметки)
│   └── даты и напоминания (ДР и другие даты)
├── Музыка
│   ├── виджет-диск в записи, у человека, у книги
│   ├── треки по ссылкам YouTube
│   └── мини-плеер, не прерывающийся при переходах
└── Сквозные разделы
    ├── экран «Сегодня», навигация, календарь
    ├── поиск и теги
    ├── настройки (шрифты, стили, уведомления, категории, данные)
    └── онбординг, корзина, статистика
```

Сквозные разделы в исходных идеях не упоминались; они описаны в
[09-cross-cutting.md](09-cross-cutting.md) и добавлены потому, что без них три модуля
не складываются в приложение. Как пользователь проходит через всё это — в
[08-scenarios.md](08-scenarios.md).

## 1.4 Сквозные связи между модулями

Исходные идеи описывали модули по отдельности. Связи ниже — проектное предложение: они
почти не усложняют реализацию, но именно из них получается цельный продукт, а не три
независимых списка.

| Связь | Зачем |
| --- | --- |
| Позиция вишлиста → человек | Отметить, кому предназначен подарок; вести «идеи подарков» для конкретного человека |
| Человек → вишлист человека | Хранить пожелания близких, чтобы не выдумывать подарок в последний момент |
| Напоминание о ДР → вишлист человека и его блок «любимое/нелюбимое» | В уведомлении о дне рождения сразу видны подсказки, что дарить |
| Запись о книге → человек | Отметить, кто порекомендовал книгу или кому её советовали |
| Любые записи → человек | Упоминание человека в тексте записи связывает запись с его карточкой (лента упоминаний) |
| Запись → музыкальный диск | «Саундтрек дня»: запись хранит то, что звучало, и возвращает настроение при перечитывании |
| Человек → его музыка | Любимые песни попадают в подсказки к дню рождения вместе с цветами и «любит / не любит» |

Все связи опциональны: ни одна анкета не должна требовать заполнения связанных сущностей.

## 1.5 Границы (что продукт не делает)

- Не является социальной сетью: нет лент, подписок, чужих профилей.
- Не является музыкальным сервисом: приложение не хранит и не раздаёт аудио, а только
  проигрывает музыку официальным плеером внешнего сервиса по ссылке (см.
  [15-music.md](15-music.md)).
- Не тянет данные из соцсетей автоматически (не парсит профили, не импортирует контакты
  без явного действия пользователя).
- Не является магазином: цена и ссылка в вишлисте — просто справочные поля, никакой
  интеграции с оплатой и корзинами.
- Не занимается вычиткой и правкой текста за пользователя (проверка орфографии — только
  штатная браузерная/системная).

## 1.6 Термины

| Термин | Значение |
| --- | --- |
| **Запись** | Единица дневника: заголовок, дата, тело в Markdown и (если создана из шаблона) набор структурированных полей |
| **Шаблон** | Заготовка записи: набор полей + предзаполненное тело. Бывает системным или созданным пользователем |
| **Поле шаблона** | Структурированное поле записи (оценка, дата, число, ссылка, тег) — в отличие от свободного текста тела |
| **Текстовый стиль** | Именованный набор параметров оформления (шрифт, размер, цвет, интерлиньяж) для заголовков, цитат, обычного текста |
| **Набор стилей (тема)** | Совокупность текстовых стилей, применяемая к записи целиком |
| **Позиция вишлиста** | Одна анкета подарка внутри вишлиста |
| **Карточка человека** | Анкета знакомого в модуле «Люди» |
| **Важная дата** | Дата, привязанная к человеку (день рождения, годовщина, произвольная дата) с настройками напоминаний |
