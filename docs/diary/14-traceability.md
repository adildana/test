# 15. Матрица покрытия исходных идей

Таблица показывает, во что превратилась каждая фраза из исходного описания. Назначение —
проверка полноты: ни одна идея не должна остаться без требования, и ни одно требование
не должно появиться «из воздуха» без пометки, что это дополнение.

Обозначения в столбце «Тип»:
**И** — прямо из исходной идеи, **У** — уточнение неоднозначной формулировки,
**Д** — дополнение, предложенное сверх исходных идей.

## 15.6 Что добавлено полностью сверх исходных идей

Эти разделы в исходном описании не упоминались, но без них приложение не собирается.
Каждый помечен как дополнение и может быть отклонён заказчиком без ущерба для остального.

| Область | Требования | Обоснование |
| --- | --- | --- |
| Экран «Сегодня» | NAV-10…NAV-16 | Точка входа, связывающая три модуля; иначе пользователь начинает с пустого списка |
| Навигация и URL-состояние | NAV-01…NAV-06 | Базовое условие пользуемости на нескольких платформах |
| Единый поиск | SRCH-01…SRCH-10 | Дневник без поиска перестаёт быть полезным на второй сотне записей |
| Теги | TAG-01…TAG-06 | Единственная сквозная группировка для записей, желаний и людей |
| Календарь | CAL-01…CAL-06 | Естественное представление и для записей по датам, и для важных дат |
| Настройки | SET-01…SET-06 | Дом для шрифтов, стилей, уведомлений и категорий |
| Онбординг и пустые состояния | ONB-01…ONB-06, 11.3 | Первые две минуты определяют, вернётся ли пользователь |
| Корзина и восстановление | NAV-40…NAV-44 | Личные данные нельзя удалять безвозвратно одним нажатием |
| Статистика | STAT-01…STAT-05 | Даёт смысл структурированным полям шаблонов |
| Приватность и безопасность | NFR-01…NFR-11 | Дневник — самая чувствительная категория данных |
| Экспорт и владение данными | NFR-20…NFR-24 | Условие доверия к сервису для личных записей |
| Офлайн и синхронизация | NFR-30…NFR-33 | Записи делают в дороге и без сети |
| Доступность | NFR-50…NFR-57 | Своими шрифтами и цветами легко сделать интерфейс нечитаемым — нужны ограничители |
| Сквозные связи модулей | 1.4, PPL-59, PPL-95, MUS-25 | Превращают отдельные списки в один продукт |
| Архитектура, API, тест-план | 12, 13, 14 | Переход от описания к реализации |
| Дизайн-система | DS-01…DS-72, 18 | В продукте со своими шрифтами и цветами без границы между интерфейсом и содержимым интерфейс станет нечитаемым |
| Переносимость данных | PORT-01…PORT-33, 19 | Обещание «данные ваши» проверяется структурой архива, а не текстом лицензии |
| Позиционирование | 20 | Объясняет, какие функции обязательны, а какие уводят на территорию Notion и Obsidian |
| Квоты и сроки хранения | NFR-80…NFR-83, 6.7 | Пределы должны быть известны заранее, а не обнаруживаться при отказе |
