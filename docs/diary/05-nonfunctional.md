# 6. Нефункциональные требования

## 6.1 Приватность и безопасность

Дневник — самая личная категория данных, какая бывает в приложениях. Требования ниже не
«для галочки»: если пользователь не доверяет продукту, он не станет вести в нём дневник.

| ID | Приор. | Требование |
| --- | --- | --- |
| NFR-01 | M | Все данные доступны только владельцу. Любой запрос к записи, человеку, вишлисту проверяет владельца, а не только наличие авторизации |
| NFR-02 | M | Передача данных только по HTTPS; файлы вложений отдаются по подписанным ссылкам с ограниченным сроком действия, а не по угадываемым путям |
| NFR-03 | M | Пароли хранятся в виде хешей современным алгоритмом; вход по e-mail и паролю с ограничением частоты попыток |
| NFR-04 | M | Блокировка приложения кодом/биометрией при возврате из фона (отдельная настройка, по умолчанию выключена) |
| NFR-05 | M | Публичная ссылка на вишлист (WL-11) отдаёт только выбранные позиции и не раскрывает ничего другого: ни людей, ни записи, ни другие вишлисты |
| NFR-06 | M | Публичные страницы закрыты от индексации (`noindex`, `robots.txt`), ссылку можно отозвать, после отзыва старый адрес перестаёт работать немедленно |
| NFR-07 | M | Приложение не отправляет данные третьим сторонам. Внешние запросы возможны только по явному действию пользователя (например, WL-10 «заполнить по ссылке»), с предупреждением о том, что сайт увидит обращение |
| NFR-08 | M | Загружаемые файлы (изображения, шрифты) проверяются по содержимому, обрабатываются в изоляции и никогда не исполняются; из изображений удаляются метаданные, включая координаты |
| NFR-09 | M | Пользовательский HTML/Markdown санитизируется при отображении и экспорте (защита от XSS через вставленный текст) |
| NFR-10 | S | Полное удаление аккаунта со всеми данными и файлами, по запросу пользователя, с подтверждением |
| NFR-11 | C | Сквозное шифрование тела записей ключом, производным от пароля пользователя. Требует решения о восстановлении доступа при утере пароля — см. Q7 |

## 6.2 Владение данными и экспорт

| ID | Приор. | Требование |
| --- | --- | --- |
| NFR-20 | M | Экспорт всех данных одним архивом: записи в Markdown, вложения файлами, структурированные данные в JSON, читаемая структура папок |
| NFR-21 | M | Экспорт выполняется без ограничений и не требует платной подписки — данные принадлежат пользователю |
| NFR-22 | S | Импорт ранее выгруженного архива с сохранением связей |
| NFR-23 | S | Регулярное автоматическое резервное копирование в выбранное пользователем хранилище |
| NFR-24 | S | Импорт записей из Markdown-файлов и папок (совместимость с Obsidian-подобными хранилищами) |

## 6.3 Офлайн и синхронизация

| ID | Приор. | Требование |
| --- | --- | --- |
| NFR-30 | S | Чтение и создание записей без сети; изменения ставятся в очередь и отправляются при появлении соединения |
| NFR-31 | S | Синхронизация между устройствами одного пользователя |
| NFR-32 | S | При конфликте изменений одной записи ни одна версия не теряется: сохраняются обе, пользователю предлагается выбрать или объединить |
| NFR-33 | S | Уведомления о датах работают и без открытого приложения (локальные уведомления на устройстве или серверная отправка) |

## 6.4 Производительность

| ID | Приор. | Требование |
| --- | --- | --- |
| NFR-40 | M | Открытие редактора существующей записи — не дольше 1 с при типичном объёме (до 20 тыс. символов) |
| NFR-41 | M | Ввод текста без заметных задержек в записи до 50 тыс. символов; форматирование применяется мгновенно |
| NFR-42 | M | Список из 1000 людей или позиций вишлиста прокручивается плавно (виртуализация списка) |
| NFR-43 | M | Загруженные шрифты не блокируют отображение текста (`font-display: swap`), кешируются на длительный срок |
| NFR-44 | S | Экспорт PDF на 100 позиций с фотографиями — не дольше 10 с, с индикатором прогресса |
| NFR-45 | S | Изображения хранятся в нескольких размерах; в списках используются уменьшенные версии |

## 6.5 Доступность и интерфейс

| ID | Приор. | Требование |
| --- | --- | --- |
| NFR-50 | M | Полное управление с клавиатуры, включая панель форматирования (ED-29); видимый фокус на всех интерактивных элементах |
| NFR-51 | M | Контраст текста и элементов не ниже уровня WCAG 2.1 AA; при выборе цвета пользователем показывается предупреждение о недостаточном контрасте |
| NFR-52 | M | Информация никогда не передаётся только цветом: у цветовых меток есть подпись или иконка (важно для блоков «любит/не любит» и категорий) |
| NFR-53 | M | Кнопки-иконки имеют текстовые названия для экранных читалок |
| NFR-54 | M | Светлая и тёмная темы, следование системной настройке |
| NFR-55 | M | Адаптивность: телефон, планшет, десктоп. Основные сценарии ввода удобны на телефоне одной рукой |
| NFR-56 | S | Уважение системной настройки «уменьшить движение» (отключение анимаций панели и переходов) |
| NFR-57 | S | Масштабирование интерфейса при увеличенном системном размере шрифта без обрезания текста |

## 6.6 Локализация

| ID | Приор. | Требование |
| --- | --- | --- |
| NFR-60 | M | Основной язык интерфейса — русский. Все строки выносятся в файлы переводов с первого дня, без зашитых в код текстов |
| NFR-61 | M | Форматы дат, чисел и денег зависят от локали; первый день недели — понедельник для русской локали |
| NFR-62 | M | Множественные числа обрабатываются правилами языка («1 книга», «2 книги», «5 книг») |
| NFR-63 | S | Английская локаль |
| NFR-64 | M | Часовые пояса: все даты и времена хранятся в UTC, отображаются в поясе пользователя; расписание напоминаний строится по местному времени пользователя |

## 6.7 Надёжность и наблюдаемость

| ID | Приор. | Требование |
| --- | --- | --- |
| NFR-70 | M | Потеря введённого текста недопустима: черновик сохраняется локально до подтверждения записи на сервере |
| NFR-71 | M | Ошибка сети при сохранении сообщается явно, с кнопкой «Повторить», без потери введённых данных |
| NFR-72 | M | Фоновые задачи напоминаний идемпотентны и переживают перезапуск сервиса без дублей и пропусков |
| NFR-73 | S | Технические логи ошибок не содержат тел записей, заметок и других личных текстов |
| NFR-74 | S | Метрики доставки уведомлений (отправлено / не доставлено), чтобы дефекты напоминаний были заметны до жалоб |
